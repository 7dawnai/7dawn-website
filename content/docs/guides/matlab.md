# MATLAB 与 Simulink

3Studio 可以连接你电脑上已安装的 **MATLAB**（含 Simulink），让 Agent 直接替你执行脚本、建模、仿真这些工作。

> ⚠️ **仅支持 Windows。** 使用前提、后台桥接程序的工作方式、通用 Python 环境设置和常见连接问题，见《[概览与通用设置](./cae-overview.md)》——本页只写 MATLAB 特有的部分。

## 配置 MATLAB

打开**设置 → 工具**标签页，往下滚动能看到 **MATLAB** 卡片。卡片默认折叠，只显示标题和状态标签；点击标题（或右侧箭头）展开后才能看到下面的检测 / Python 解释器 / 测试连接等设置。

- **状态标签**：卡片顶部有一个状态标签，MATLAB 常见会出现这几种：

  | 标签 | 颜色 | 含义 |
  |---|---|---|
  | 未检测到 | 灰 | 还没设置有效路径 |
  | 失效 | 红 | 曾经设置的路径现在校验不通过（比如卸载了 MATLAB），或自动检测到了不受支持的版本；展开卡片后会显示原因，只有存在可清除的已选失效项时才会提供"清除"按钮 |
  | 检测异常 | 金 | 检测过程本身出错了（跟"未检测到"不同，这是检测机制自身的问题），可点"检测"重试 |
  | 准备中… | 金 | 正在准备 Python 环境 |
  | 出错 | 红 | 准备环境时失败，下方会显示具体原因，并出现一个"重试"按钮 |
  | 桥未运行 | 金 | 环境已就绪，但桥接进程还没启动，可点"重试"再次尝试 |
  | 就绪 | 绿 | 一切正常，可以使用 |

- **选择 MATLAB 安装目录**：点击"选择 MATLAB 文件夹…"，在弹出的文件夹选择器里选中你电脑上 MATLAB 的安装目录。**请选到版本目录本身**（形如 `C:\Program Files\MATLAB\R2023b`）——3Studio 从目录名识别版本，据此安装匹配的 MATLAB Engine；如果你顺手点进了它下面的 `bin` 子目录，3Studio 也认，会自动往上归到版本目录。选中后卡片会显示识别到的版本号和路径；如果选的目录里找不到 MATLAB，会提示重新选择版本目录。
- **支持的 MATLAB 版本**：R2022a 到 R2025a。不在此范围内的版本一律不会被启用，手动指定和自动检测两条路都一样，都不会等到装依赖时才失败：
  - **手动指定时**：会当场提示"暂不支持"并列出支持的版本。
  - **自动检测到时**（比如你装了一个比这个范围更新的版本，但没有手动指定过目录）：卡片会显示"失效"；展开后会显示该版本不受支持的具体原因。3Studio 不会启用这份安装，也不会把卡片显示为"就绪"。想恢复使用 MATLAB，可以安装一个在支持范围内的版本，或者用上面的"选择 MATLAB 文件夹…"手动选择另一份已安装的受支持版本。
- **Python 解释器**：桥接程序需要的 Python 版本**随 MATLAB 版本而不同**（例如 R2022a 需要 3.8–3.9，R2023a 需要 3.8–3.10，R2023b 及以后需要 3.9 起）——这是 MathWorks 官方的对应关系，3Studio 按你选的 MATLAB 版本自动挑选兼容的解释器。如果不填，会用系统上找到的兼容版本；也可以点"选择 Python…"手动指定一个解释器路径，不兼容时会直接告诉你该装哪个版本区间。**更换解释器后需要重启应用才生效**。
- **桥接端口**：只读显示，正常情况下不需要改。
- **测试连接**：点击"测试连接"按钮，3Studio 会尝试跟桥接程序握手，成功时会显示几项信息：`Status`（桥接进程状态）、`MATLAB Engine`（MATLAB 引擎是否成功启动）、`Workspace`（当前使用的工作目录）；如果 MATLAB 引擎启动失败，还会额外显示 `engine_error` 的具体错误信息。
- **导出诊断报告**：连接不上、或状态一直是"未检测到"时，点这个按钮会现场做一遍检查（查注册表、逐个试着导入依赖、握一次手），把结果连同你的配置一起存成一个 Markdown 文件。点下去之后会跑几十秒（要逐项实地检查），按钮会显示"正在收集…"，请等它结束。把这个文件发给我们，能大幅加快排查。报告是纯文本，发之前你可以自己打开看一眼——里面包含安装路径和用户名（这些往往正是问题所在），但不包含许可证密钥、你的文件内容和聊天记录，也不含运行日志。

> **它跟侧边栏会话菜单里的"导出聊天记录与日志"不是一回事**：那个导出的是某次对话的过程与日志，用于排查"这次对话哪里出了问题"；这里这个只回答"MATLAB 为什么配不上/连不上"。连接有问题就用这个。

> **MATLAB 不受通用「Python 环境」卡片影响**：MATLAB 使用它自带的 Python，不参与设置页顶部那张卡片的基座 / 目录设置。

## 连接状态徽章

除了设置页面里的卡片，侧边栏底部还有一个独立的"运行时"按钮，点开会展开一个小面板，里面有一项 **Bridge**，专门显示 MATLAB 桥接后台进程当前的运行状态：

| 显示文案 | 含义 |
|---|---|
| Running | 桥接进程正常运行 |
| Error | 桥接进程出错 |
| Stopped | 桥接进程已停止 |
| Unavailable | 桥接进程还未启动 / 暂不可用 |

> 这几个状态文案目前是英文原文，不随界面语言切换。

## 让 Agent 使用 MATLAB

配置好之后，你可以在对话里直接让 Agent 帮你做以下这些事，Agent 会自动选用对应的能力，不需要你了解具体是怎么调用的：

- **执行 MATLAB 脚本 / 命令**：比如让 Agent 帮你算一段公式、跑一段 `.m` 脚本，变量会在同一次对话里持续保留，后续可以接着引用。
- **运行 Simulink 仿真**：Agent 可以直接跑一个已有的 Simulink 模型，拿到关键结果摘要、自动生成的图表，并保留完整的仿真数据文件供后续深入分析。
- **搭建 / 修改 Simulink 模型**：新建模型、往模型里添加功能模块（比如积分器、增益模块）、批量修改模型结构（一次性加模块、连线、删除、改参数），以及在模型卡住时强制重置。
- **读取仿真结果**：从 MATLAB 工作区里取回某个变量的值，或者把之前仿真产生的数据文件重新加载进来做进一步计算。
- **导出图表**：把时间序列数据画成图并导出为 PNG 或 SVG 图片文件，方便你在报告里直接使用。
- **在 MATLAB 编辑器里打开文件**：让 Agent 帮你在 MATLAB 里打开某个模型或脚本文件。这个操作会执行文件自带的加载脚本，属于有风险的操作——默认情况下会先弹出一张审批卡片等你确认（审批卡片的用法见《[与 Agent 对话](./chat.md)》）。
