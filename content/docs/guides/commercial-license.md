# 商业版授权

3Studio Commercial 使用邮箱和激活码完成授权。激活成功后，本机可以在授权有效期和设备数量限制内使用商业版能力。

## 激活码

激活码以你收到的邮件或客服消息为准。

输入激活码时请注意：

- 可以从邮件或客服消息中复制粘贴。
- 不要改写字符、大小写或分隔符。

## 激活设备

同一个激活码可以在允许的设备数量内重复使用。例如授权允许 2 台设备时，可以在台式机和笔记本上分别激活。

如果设备数量已达上限，请先停用旧设备，或联系管理员处理。

## 邮箱

激活时需要填写邮箱。管理员预先绑定邮箱时，激活邮箱必须与绑定邮箱一致。未预先绑定邮箱的授权会在第一次成功激活时绑定该邮箱。

## 查看授权信息和诊断信息

激活成功后，设置里的 **License** 区域会显示席位 ID 和设备标识的前 4 位、后 6 位，便于快速核对当前授权和设备。

点击 **复制诊断信息** 时，复制内容会包含完整的组织 ID、席位 ID 和设备 hash，方便管理员排查授权问题。
