# 常见问题

## 为什么设置里没有"浅色主题"选项？

3Studio 目前只有深色界面这一种外观，设置页里没有主题切换开关，也没有计划中的浅色模式。这是当前版本的既定状态，不是缺失或 bug。完整的设置项说明见《[设置与通知](./guides/settings.md)》。

## 为什么 Agent 干活的时候，我没收到系统通知？

只要 3Studio 窗口正处于你当前聚焦查看的状态，系统通知就不会弹出——3Studio 认为你已经在看着界面了，不需要再额外提醒你，这样可以避免正在使用时被打断。把窗口切到后台（比如切换到其他应用）后，Agent 完成任务、出错，或后台任务结束时才会弹出系统通知；点击通知会把 3Studio 窗口带回前台。目前设置里没有单独关闭这些通知的开关。详见《[设置与通知](./guides/settings.md)》。

## 为什么附件传不上去，或者被拒绝了？

单条消息最多能带 **8 个附件**；图片单个不超过 **5MB**，文本类文件（如 `.md` `.txt` `.csv` `.json` `.yaml` `.yml` `.log` `.toml`）单个不超过 **1MB**；其他类型的文件（如 PDF、压缩包、可执行文件）目前不支持作为附件添加。超出数量、超出大小，或文件类型不支持时，界面会弹出提示条说明具体原因，附件不会被添加进去。完整的添加方式（拖拽 / 粘贴 / `@` 引用）见《[与 Agent 对话](./guides/chat.md)》。

## 为什么重启后，之前打开的多个工作区不见了？

左侧工作区切换栏里"当前打开着的多个工作区"这份列表，只在这一次运行期间有效——关闭并重新启动 3Studio 后会清空，回到首页。但你打开过的每个项目都会被记录进首页的"最近"列表，这份列表是长期保留的，不会因为重启消失；从"最近"列表重新点开同一个工作区时，3Studio 还会记住你上次在这个工作区里选中的 Agent 和会话，直接帮你恢复回去。详见《[工作区与文件](./guides/files.md)》。

## 回放里能看到当时的屏幕画面吗？

不能，回放不是屏幕录像。3Studio 记录的是 Agent 当时调用了哪些工具、参数是什么，回看时会按这份记录重新"跑"一遍，在 Computer 面板里重建出当时的工具调用、文件读写等状态，而不是真实屏幕像素的录制。另外截至目前的版本，界面里还没有一个入口可以直接打开某次已完成任务的回放视图——记录本身会在后台自动保存，但暂时无法从界面里回看、播放或跳转到某一步。详见《[回放](./guides/replay.md)》。

## 为什么在 macOS 上找不到 MATLAB / STK / Ansys / Creo / HyperMesh / Nastran 的设置？

CAE/CAD 软件集成（MATLAB、STK、Ansys、Creo、HyperMesh、MSC Nastran）目前只支持 Windows。在 macOS 或 Linux 上，设置页里"工具"标签下不会出现这部分内容，属于当前版本的既定限制，不是配置遗漏。详见《[支持的 CAE/CAD 软件：概览与通用设置](./guides/cae-overview.md)》。

## 怎么更换 Agent 使用的模型？

模型配置是**全局**的：进入设置页的 **LLM** 标签，里面的 Model Provider 区域配置好之后，所有 Agent 会共用同一份模型配置，无法在某个 Agent 的编辑器里单独指定不同模型。详见《[设置与通知](./guides/settings.md)》。

## 会话记录存在哪里？能导出吗？

会话记录保存在你这台电脑本地，不会自动同步到其他设备或账号。想要导出某次对话，右键点击会话列表里对应的会话，在弹出菜单里选"导出对话"，会打开系统的"保存文件"对话框；导出的是一份 JSON 文件，包含这次对话的基本信息（所属 Agent、工作区、导出时间）和完整的消息记录——工具运行输出完整保留，图片等附件只保留文件引用、不含数据本身。详见《[Agent 与会话管理](./guides/agents.md)》。

如果是要向开发者反馈问题，用右键菜单里的"导出对话+日志"：除对话记录外，还会打包应用运行日志（只含该会话时间段）、版本环境信息和已脱敏的配置，导出为一个 zip 文件，方便一次性发给开发者定位问题（如果你运行过连接诊断，还会包含一份诊断结果 `connection-diagnosis.json`）。

## 消息下方显示"运行失败"是什么意思？

这表示这一轮模型调用在服务商那里失败了，卡片里会原样显示服务商返回的原因——最常见的是 API 配额用完（例如提示 "You've reached your usage limit"，此时需要到对应服务商充值续费，或在设置里更换模型服务）。灰色的"已停止"则表示这一轮是你手动停止的，不是故障。如果原因看不懂或反复出现，右键该会话选"导出对话+日志"，把导出的 zip 发给开发者定位。

## 发消息报"Local agent runtime not available"，或左下角状态灯变红，怎么办？

3Studio 的对话由一个独立的本地引擎进程支撑。左侧栏底部的状态灯反映它的状态：**绿色**=正常；**黄色**=正在启动，或还没配置模型服务；**红色**=启动失败。点一下状态灯会展开面板，"本地运行时"一行显示具体状态。

如果是黄色并提示尚未配置模型服务，到设置页的 **LLM** 标签配好即可，不是故障。红色才表示引擎真的没能启动。

面板里还会出现一个**"复制诊断信息"**按钮。点它会把定位这个问题所需的全部信息（系统版本、CPU、引擎程序路径与大小、失败原因、引擎最近的输出）复制到剪贴板，直接粘贴发给开发者即可——里面的密钥类内容已自动脱敏。

状态灯变红最常见的原因，是这台电脑的系统环境不满足引擎程序的运行要求——此时失败原因里会带一个 `0x` 开头的系统错误码和它的含义（例如提示某个动态链接库缺少所需的导出函数，通常意味着系统版本偏低）。这种情况请把诊断信息发给开发者。

其中"CPU 太老"这一类不用你操心：安装包里的引擎程序用的是兼容性最好的那一档，2011 年以后的处理器都能跑，不存在需要单独下载的"兼容版安装包"。

## 为什么我发了新消息，会话没有排到列表最前面？

会话列表按创建 / 重命名 / 首次打开的时间从新到旧排列，在同一会话里继续发送新消息不会让它重新浮到列表最前面——这是既定的排序规则，不是没有及时刷新。详见《[Agent 与会话管理](./guides/agents.md)》。
