# STK

3Studio 可以连接你电脑上已安装的 **STK**（Systems Tool Kit，卫星轨道与任务分析软件），让 Agent 直接替你搭场景、算轨道，而不用你自己在 STK 里手动点。

> ⚠️ **仅支持 Windows。** 使用前提、后台桥接程序的工作方式、通用 Python 环境设置和常见连接问题，见《[概览与通用设置](./cae-overview.md)》——本页只写 STK 特有的部分。

## 配置 STK

打开**设置 → 工具**标签页，往下滚动能看到 **STK** 卡片，默认折叠，点击标题（或右侧箭头）展开后才能看到全部设置。跟 MATLAB 相比，主要差异是：

- **有"检测"按钮**：点击"检测"，3Studio 会自动探测你电脑上是否装了 STK（不需要你手动选路径）；检测到时会显示版本号，检测不到时会在下方给出原因提示。支持 STK 9 到 STK 20，按主版本号自动识别；同时装了多个版本时使用版本号最高的那个。跟其他几款引擎不同，STK **没有"手动添加"入口**（探测本身只读注册表信息，没有校验用户填的路径的手段），只能依赖自动探测。状态标签常见有：未检测到（灰，还没探测到）、失效（红，曾经探测到的安装现在校验不通过，可点"清除"后重新探测）、检测异常（金，探测机制本身出错，会显示原因）、准备中…／出错／桥未运行／就绪，跟 MATLAB 卡片的含义一致（见《[MATLAB 与 Simulink](./matlab.md)》）。
- **Python 解释器（手动指定）**：STK 桥接需要 Python 3.9–3.13。手动指定的解释器是最高优先级的覆盖项；不指定时依次使用通用基座 Python（设置页顶部的「Python 环境」卡片，见《[概览与通用设置](./cae-overview.md)》）、自动发现。点「选择 Python…」手动指定；更换后不用重启整个应用，会在该引擎**下次启动或重建环境时**生效。
- **隔离环境位置**：STK 的 Python 依赖默认安装在一个独立的虚拟环境里（跟你系统上的 Python 互不影响），卡片上有"环境位置"一行显示当前位置，可以点"更改位置…"换到别的磁盘（比如 C 盘空间不够时）。展开后的卡片上一直有一个"重建隔离环境"按钮，点一下就会用当前的基座 Python 重新搭建这个隔离环境（比如切换了通用基座之后想让 STK 立即用上新版本，就点它）。如果检测到当前用的其实是系统 Python 而不是这个隔离环境，还会额外提示"使用系统 Python（未隔离）"，提醒你去点这个按钮修复。
- **测试连接**：跟 MATLAB 类似，点击后显示 `Status`（桥接进程状态）、`Sidecar`（STK 侧的后台服务状态，若有）、`STK`（STK 软件本身的连接状态，若有）；连接失败时会显示 `stk_error` 的具体信息。
- **导出诊断报告**：点"检测"一直检测不到、或连接不上时，点这个按钮会现场做一遍检查（逐个版本查 STK 的注册信息、逐个试着导入依赖、握一次手），把结果连同你的配置一起存成一个 Markdown 文件。点下去之后会跑几十秒（要逐项实地检查），按钮会显示"正在收集…"，请等它结束。把这个文件发给我们，能大幅加快排查。报告是纯文本，发之前你可以自己打开看一眼——里面包含安装路径和用户名（这些往往正是问题所在），但不包含许可证密钥、你的文件内容和聊天记录，也不含运行日志。

> **它跟侧边栏会话菜单里的"导出聊天记录与日志"不是一回事**：那个导出的是某次对话的过程与日志，用于排查"这次对话哪里出了问题"；这里这个只回答"STK 为什么检测不到/连不上"。检测或连接有问题就用这个。

> **STK 没有侧边栏"运行时"面板里的连接状态徽章**——STK 的连接状态只能在设置页面的这张卡片里查看，不会出现在侧边栏底部的"运行时"面板中。

> **关闭 3Studio 时 STK 会怎样**：3Studio 自己启动的 STK 会在退出时一并关闭；**你自己打开的 STK 不会被关闭**——即使 3Studio 正连着它工作。3Studio 在连接前就会判断这个 STK 是不是自己启动的，判断不出来时一律按「你的」处理，宁可留一个窗口给你手动关，也不会关掉可能有未保存场景的实例。**3Studio 自己启动的那个 STK 窗口不要用来存放你的工作——退出时会被直接终结，不会提示保存。**

## 让 Agent 使用 STK

配置好 STK 之后，Agent 具备的能力围绕"搭场景、算轨道"展开：

- **创建仿真场景**：新建一个 STK 场景，可以指定起止时间；首次调用会自动启动 STK 桌面程序（需要十几秒）。
- **添加卫星**：按开普勒轨道根数（近地点/远地点高度、倾角、升交点赤经等）把一颗卫星加进当前场景，并可以指定轨道传播器类型（如 J4 摄动模型、HPOP 高精度模型等）。
- **添加地面站**：按经纬度和海拔高度，把一个地面设施（比如地面站）加进当前场景。
- **重新计算轨道**：对已有卫星重新执行一次轨道传播计算。
- **计算可见性窗口**：计算两个对象（比如某颗卫星和某个地面站）之间什么时候能"看得见"彼此，返回具体的时间区间和总时长。
- **批量创建星座**：不用一颗一颗手动添加——按 Walker 星座的参数（卫星总数、轨道面数、相位因子、倾角、高度等）让 Agent 一次性把整个星座展开进场景，还可以选择性地给每颗卫星挂一个圆锥形波束（指定半锥角）。
- **计算覆盖分析**：针对一组卫星或整个星座，按等仰角或等地心角约束计算它们对某片区域的覆盖情况，返回最大覆盖空档时长、平均/最小覆盖率这类判据级结果。星座规模大或分析时长长时这类计算可能要跑几十分钟，3Studio 会把它放进**后台任务**执行，不会卡住你和 Agent 的对话——你可以随时打开后台任务列表查看计算进度，算完 Agent 会自动读取结果继续往下做。
- **保存 / 打开场景**：让 Agent 把当前场景保存成 `.sc` 场景文件留档，或者反过来打开一个已有的 `.sc` 文件——打开后场景会直接显示在 STK 桌面程序窗口里，方便你亲眼查看核对。
- **执行底层 STK 命令 / 编写脚本**：对于以上几类做不到的更细操作（比如设置卫星姿态、控制场景动画播放、调整三维显示），Agent 可以直接执行一条 STK 原生命令；遇到更复杂的需求（比如链路预算、干涉分析），Agent 还能直接编写并运行一段 STK 脚本来完成。这两种都是直达底层、影响面较大的操作，默认会先弹出审批卡片等你确认（审批卡片的用法见《[与 Agent 对话](./chat.md)》）。
